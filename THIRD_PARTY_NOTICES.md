# Third-party notices

## CPython

The Windows portable build embeds a CPython runtime copied from the user's local
Python installation. CPython is distributed under the Python Software Foundation
License. The portable build includes the `LICENSE.txt` shipped with CPython at
`python/LICENSE.txt`.

<https://docs.python.org/3/license.html>

## Tcl/Tk

CPython's Tkinter support uses Tcl/Tk, distributed under BSD-style licenses.
The portable build includes the Tcl/Tk runtime files shipped with CPython.

## Other components

Sentinel has no mandatory third-party Python runtime dependencies.
Chrome, Edge, Node.js, Claude clients and proxy software are optional external
programs and are not bundled.
