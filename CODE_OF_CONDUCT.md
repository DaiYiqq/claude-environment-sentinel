# Code of Conduct

## Our commitment

We want this project to be a respectful, useful place for users and contributors
of different backgrounds, languages and experience levels.

## Expected behavior

- Be respectful and specific when discussing code or behavior.
- Assume good faith, but support claims with reproducible evidence.
- Protect privacy: never post another person's credentials, cookies, tokens,
  IP addresses, snapshots or account details.
- Keep security reports private through GitHub Security Advisories.
- Accept that the project has a safety boundary: it does not bypass server-side
  risk controls and does not guarantee account outcomes.

## Unacceptable behavior

- Harassment, threats, discrimination or personal attacks.
- Publishing private information or credentials without permission.
- Deliberately misleading security claims.
- Spam, repeated off-topic posts or promotional abuse.
- Attempts to use the project to access accounts or systems without
  authorization.

## Enforcement

The maintainer may edit or remove content, close issues, reject pull requests
or temporarily restrict participation. Serious or repeated violations may lead
to a permanent ban from project spaces.

Report conduct problems privately through the contact listed in
[AUTHORS.md](AUTHORS.md) or GitHub's reporting tools. Do not include secrets in
the report.

## Scope

This code applies to GitHub Issues, Discussions, Pull Requests, reviews and
other project-managed spaces.
